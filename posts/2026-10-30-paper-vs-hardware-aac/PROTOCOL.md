# WS-049 · Adaptive Action Chunking (Liang et al., CVPR 2026, arXiv 2604.04161) on SmolVLA — gates 0–1 protocol, frozen 2026-10-27

Prompt: `journal/prompts/2026-10-27_aac_adaptive_chunking.md`. Venue checked: CVPR 2026 (the prompt's "venue unconfirmed" is superseded).

**Method as implemented (paper §4, Eq. 2–5, Alg. 1).** At a decision frame p, draw N = 20 SmolVLA chunks (H = 50) from the same observation with independent noise (seeds fixed per episode / frame). Continuous part: the 5 arm joints in robot units (degrees), one 5×5 covariance Σ_i per timestep i over the N samples, E_i = ½ log[(2πe)^5 det(Σ_i + 1e-6 I)]. Discrete part: gripper command thresholded at the open/close threshold of the rollout tools (g_open of `g9c2_rule.json`), p = closed count / N, E_i^g = −p log p − (1−p) log(1−p). Ē_h = (1/h) Σ_{i<h} (E_i + E_i^g). h* = max(argmax_{h ∈ 1..H−1} (Ē_{h+1} − Ē_h), ξ), ξ = 2 (deviation from the paper's magnitude-based ξ: joint-space absolute commands have no translation / quaternion magnitude; the prompt fixes ξ = 2). **Executed chunk = sample 0** (the paper does not say which of the N is executed; sample 0 uses the same noise as the fixed arm, so the arms are paired).

**Gate 0 (offline, $0).** Model `ravediamond/smolvla_2026-09-24_14-34-40` @ `c1d76f6`; episodes = the 20 of `g13b_summary.json` (`ravediamond/so101_bowls_all`), decision frames p = t − 25 for the study's grid t = 25, 50, … (the 254 boundaries).
- **A1** grasp = first gripper close of the recorded command (W1-C1 anchor rule); release = first open after it. Grasp window: |p − grasp| ≤ 15 frames; transport: grasp + 15 < p < release. **Bar: median h* (transport) ≥ median h* (grasp window) + 2.**
- **A2 / A3** four arms at each decision p, delays d ∈ {8, 12, 20}: *fixed* switches at p + 25 (s = 25, new chunk from the observation at p + 25); *AAC* switches at p + s with s = clip(h*, ξ, 50 − d − 2), new chunk from the observation at p + s. Each with *naive* (fresh chunk) and *overwrite* (the study's gradient-free prefix overwrite, leftover = prev[s:]). Metric: the study's `jump_ratio` (boundary_metrics, five arm joints). A2 descriptive (no bar). **A3 bar: median jump (AAC + overwrite) ≤ median jump (fixed + overwrite) at d = 8** (12 and 20 reported).

**Gate 1 (offline, $0; MAXN_SUPER + jetson_clocks as the 238 ms figure, owner confirms the sudo).** vla.cpp SmolVLA GGUF on the Orin: wall time per decision for N = 1, 5, 10, 20, 40 (batched if vla.cpp has a batched sampling path, else sequential), peak memory. **A4 bar: N = 20 total ≤ 298 ms (≤ 25 % over 238 ms).** If vla.cpp has no batched path, the sequential time is reported as the upper bound and A4 is judged on it.

Gate 2 (arm) is not planned: the bowls task is at 9/10 for SmolVLA, so a +15-point effect cannot be shown; a harder protocol (§29 off-nominal layouts) would be proposed first.
